## USB 接电常亮（dongle 版）

此版本为左右键盘加入独立的 USB 电源检测。USB 只接充电器也可以，不需要连接电脑；dongle 的无线连接方式保持原样。

- 接上 USB 电源：该半边 RGB 保持亮灯，闲置不熄灯，充满后继续有效。
- 拔掉 USB：恢复该半边原来的 RGB 开关偏好；开启灯光时仍按空闲时间自动熄灯。
- 接电常亮是临时状态，不会把“开灯”写成电池模式的开关偏好。
- 保留原有颜色、特效与最大亮度 60% 的限制。这里的“常亮”指不因闲置而熄灯，仍使用当前特效。
- 左右两边分别检测自己的 USB 电源：需要两边都常亮，就给两边都供电。

### 自己设置

在 `config/offsetkey.conf` 中可修改原有 RGB 亮度、颜色、特效和闲置时间。

要取消接电常亮，在下面两个文件各追加一行，然后重新构建固件：

- `boards/shields/offsetkey/offsetkey_peripheral_left.conf`
- `boards/shields/offsetkey/offsetkey_peripheral_right.conf`

```ini
CONFIG_OFFSETKEY_USB_RGB_ALWAYS_ON=n
```

默认启用此功能。接电期间 RGB_ON / RGB_OFF 设置的是拔电后的电池开关偏好；接电常亮优先。亮度和特效按键仍可使用。

### 下载和刷入

在 Actions 中选择 **Build ZMK firmware**，用 `dongle` 分支运行构建。成功后下载 **firmware** 压缩包。

左右键盘分别刷入名称含 `offsetkey_peripheral_left` 和 `offsetkey_peripheral_right` 的 UF2。
接收器固件名称为 `offsetkey_dongle.uf2`。如果设备仍使用较早的固件，应将这三个设备升级为同一次构建的版本，以保持兼容。
**不要将 `settings_reset` 固件当作正常键盘固件刷入**，它用于清除设置。

此功能读取 nRF52840 的 USB VBUS 电压，保留外围键盘的 `CONFIG_ZMK_USB=n`。
构建会先应用 `patches/usb-powered-rgb.patch`；ZMK 固定在补丁验证过的提交。
接电时防止深度休眠，拔电后继续使用原来的休眠超时。如果键盘已经深度休眠，插线后未唤醒，请按键唤醒。
